# Kyoto Washi

Rice paper, sumi ink and one hanko stamp. Kyoto Washi is a light, borderless, serif theme where almost everything is ink on paper and a single vermilion, #B7282E, marks the one thing that matters on each screen. It is built for rooms you want to stay quiet: meditation timers, tea and sleep routines, calm home scenes. Themes are a Pro feature; a free user sees the default look.

**When to use:** Meditation timers, tea and sleep routines, calm home scenes.

**Light and dark:** Pinned to light with scheme-neutral values in the base theme. Sibling variants: sumi-night.

Apply it by copying the `tokens` object into the layout `theme` (see [[theming]]) and the `appearance` object into the layout `appearance`. Rules that still apply to it are in [[style-rules]]. Themes need Connect+ Pro on the phone; without it the default glass look is drawn.
