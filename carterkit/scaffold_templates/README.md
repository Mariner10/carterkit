# __NAME__

`python hello.py` prints a QR; scan it with the CAR-TER app (layout list -> Scan) and the layout lands on the phone. Every save of hello.py pushes the new layout and behaviour; `carterkit repl hello.py` adds a live prompt.
Have a Connect+ hub credential? Save it as `secrets/hub.json` (git-ignored) to use the managed relay instead of your LAN.
